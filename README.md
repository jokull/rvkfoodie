# rvkfoodie

Reykjavík Foodie — curated food guides sold to hotels as an annual B2B
subscription. The guides are the deliverable; the product is the ongoing
curation, maintenance, and delivery of trusted local recommendations.

## Stack

- **TanStack Start** (Vite) on Cloudflare Workers via `@cloudflare/vite-plugin`
- **Drizzle ORM** `1.0.0-rc.4` + **D1** (`drizzle-orm/d1`)
- **result-rpc** — typed RPC: one closed failure union per procedure, entity
  cache, SSR hydration. Contract in `src/contract.ts` is the only result-rpc
  surface client code imports; handlers live in `src/rpc-server.ts`.
- Bindings via `import { env } from 'cloudflare:workers'`; types generated by
  `wrangler types` into `worker-configuration.d.ts` (committed).

## Scripts

```sh
pnpm dev                  # vite dev on :3000 (workerd SSR via cloudflare plugin)
pnpm build                # vite build
pnpm preview              # local production preview
pnpm deploy               # build + wrangler deploy
pnpm check                # vite build + tsc --noEmit
pnpm cf-typegen           # wrangler types
pnpm db:generate          # drizzle-kit generate → drizzle/
pnpm db:migrate           # apply migrations to local D1
pnpm db:migrate:remote    # apply migrations to remote D1
pnpm db:seed              # seed local D1
pnpm db:seed:remote       # seed remote D1
```

Local D1 state lives in `.wrangler/` (gitignored).

## Layout

- `src/schema.ts` — Drizzle schema (seed shape; full editorial model is
  charted in `.wayfinder`)
- `src/rpc-server.ts` — server-only router + fetch handler (Drizzle/D1)
- `src/ssr.ts` — `createServerFn` loaders that prefetch and dehydrate
- `src/routes/api.rpc.ts` — mounts the RPC handler at POST `/api/rpc`
- `.wayfinder/` — decision map + tickets for the product build-out
- `.oldsite/` — legacy archive (D1 dump, venue data, old docs)

## Email

is in beta — local emulation works without approval; remote deploy needs the
beta grant. Configure a verified destination address once approved.
